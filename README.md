# 星火学习

面向手机使用的入党考试刷题 PWA。支持单选、多选、判断、填空、简答和论述六种题型，练习进度、错题和统计记录本地优先保存，并可通过私人密码在手机和电脑之间同步。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run start
```

## 数据

- 正式题库源文件：`public/data/questions.json`
- 生产构建会自动把题库同步到浏览器可访问的根路径。
- 学习记录首先写入 `localStorage`；连接私人同步后，会同时写入 Zeabur 持久卷。
- 清理浏览器数据或卸载 PWA 前，请先在设置页导出学习数据。

## 单用户同步

在 Zeabur 服务中挂载 `/data`，并设置：

```text
SYNC_PASSWORD=私人同步密码
SYNC_DATA_PATH=/data/study-data.json
```

随后在各设备的设置页输入同一密码。网页通过同源 HTTPS 调用同步接口，不会把密码写入仓库或同步数据文件。

连接后，本地变化会自动上传；页面重新回到前台时会立即拉取，持续打开时每 30 秒检查一次云端更新。“立即同步”按钮仅用于需要马上确认时手动触发。

## 部署

项目已经包含 `zbpack.json`，可直接连接 GitHub 仓库部署到 Zeabur。详细步骤见 `ZEABUR_DEPLOY.md`。

## 内容说明

当前题库包括：

- 官方原题：共产党员网《二十大党章知识测试题》37 道（20 道单选、17 道多选），来源为官方 PDF `https://download.12371.cn/wenjian/2022/10/30/esddz600.pdf`。
- 官方发布：共产党员网《党的二十大精神应知应会百题》100 道填空题，页面标注来源为中国组织人事报；20 个官方分期页面和原始问答快照保存在 `data/official/12371-twentieth-congress-100.json`，可通过 `node scripts/import-official-twentieth-congress-bank.mjs` 离线、幂等地重建导入。
- 生成补充：依据 2022 年 10 月 22 日通过的《中国共产党章程》整理的 100 道单选题和 100 道判断题。
- 流程演示：简答题、论述题各 3 道。

上述 37 道《二十大党章知识测试题》和 100 道《党的二十大精神应知应会百题》是两套不同的官方题集；前者不附解析，页面会明确提示“官方材料未附解析”。这不是完整的《二十大党章600题》600 道题库；党史题库当前暂不提供。
